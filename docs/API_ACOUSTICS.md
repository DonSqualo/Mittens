# Acoustics Module API Documentation

**Module:** `stdlib.acoustics`  
**Purpose:** 2D standing wave field computation for acoustic manipulation  
**Status:** Stage 11 - Complete and integrated with renderer

## Overview

The Acoustics module computes time-dependent acoustic pressure fields generated by two opposing ultrasonic sources in a rectangular bath. It implements the standing wave equation for superposition of plane waves and provides field visualization via pressure-to-color mapping.

**Key Features:**
- 2D XZ plane standing wave computation
- Grid-based pressure field (81×41 grid)
- Node/antinode detection and analysis
- Bilinear interpolation for arbitrary point sampling
- Pressure gradient computation for body forces
- RGB color mapping (blue=low pressure, red=high pressure)
- Full serialization support

## Core Functions

### StandingWaveField()

Compute the complete acoustic pressure field for a standing wave configuration.

```lua
local field = StandingWaveField(
  bath_config,     -- Bath geometry table
  source_config,   -- Speaker configuration (optional)
  params,          -- Simulation parameters
  time,            -- Current time (seconds)
  plane_offset     -- Y offset for XZ plane (default: 0 for center)
)
```

**Parameters:**

- **bath_config** (table):
  ```lua
  {
    length = 2000,      -- Bath length X (mm)
    width = 600,        -- Bath width Y (mm)
    depth = 400,        -- Bath height Z (mm)
    center_z = 200,     -- Acoustic source Z position (mm)
  }
  ```
  Default: `Acoustics.DEFAULT_BATH`

- **source_config** (table, optional):
  ```lua
  {
    left = {
      x = -1000,            -- Left speaker position (mm)
      y = 0,
      z = 200,
      amplitude = 100,      -- Pressure amplitude (Pa)
      phase = 0,            -- Phase offset (radians)
    },
    right = {
      x = 1000,             -- Right speaker position (mm)
      y = 0,
      z = 200,
      amplitude = 100,      -- Usually 180° out of phase
      phase = math.pi,      -- 180° for standing wave
    }
  }
  ```
  Default: Speakers at bath ends, 180° out of phase

- **params** (table):
  ```lua
  {
    frequency = 0.02,        -- Driving frequency (Hz)
    amplitude = 100,         -- Pressure amplitude (Pa)
    phase_sweep = 0.1,       -- Phase sweep rate (Hz) for moving wave
    medium_speed = 1524,     -- Speed of sound in medium (m/s)
  }
  ```
  Default: `Acoustics.DEFAULT_PARAMS` (water at 37°C)

- **time** (number): Current simulation time in seconds (for phase evolution)

- **plane_offset** (number): Y coordinate of the XZ plane to compute (mm). Use 0 for centerline.

**Returns:**
A field table with computed pressure grid and analysis methods (see **Field Structure** below).

### AcousticSource()

Define an individual acoustic point source.

```lua
local source = AcousticSource(
  id,           -- string: unique identifier
  position,     -- {x, y, z}: source position (mm)
  amplitude,    -- number: pressure amplitude (Pa)
  frequency,    -- number: frequency (Hz)
  phase         -- number: initial phase offset (radians, optional)
)
```

**Properties:**
```lua
source.id           -- Unique identifier
source.position     -- {x, y, z} position
source.amplitude    -- Pressure amplitude (Pa)
source.frequency    -- Driving frequency (Hz)
source.phase        -- Phase offset (radians)
source.omega        -- Derived: angular frequency (rad/s)
source.wavelength   -- Derived: wavelength (mm)
source.wavenumber   -- Derived: wave number k (1/mm)
```

### PressureToColor()

Convert normalized acoustic pressure to RGBA color for visualization.

```lua
local rgba = PressureToColor(pressure_normalized)
```

**Parameters:**
- `pressure_normalized` (number): Normalized pressure in range [0, 1]

**Returns:**
```lua
{
  r,    -- Red channel: high at high pressure (antinodes)
  g,    -- Green channel: peaks at mid pressure
  b,    -- Blue channel: high at low pressure (nodes)
  a,    -- Alpha: 0.6 (semi-transparent for overlay)
}
```

**Color Scheme:**
- **Blue nodes** (p ≈ 0): Destructive interference, pressure minima
- **Purple/Magenta** (mid): Transition regions
- **Red antinodes** (p ≈ 1): Constructive interference, pressure maxima
- **White** (p > 1): Over-pressure regions (clipped at 1.0)

### AcousticSimulation()

Integrate acoustic field computation with the Simulation engine.

```lua
local sim = AcousticSimulation(
  sim_engine,           -- SimulationEngine from stdlib.simulation
  acoustic_config       -- Acoustic configuration table
)
```

**acoustic_config:**
```lua
{
  bath = {length = 2000, ...},        -- Bath geometry (optional)
  sources = {left = {...}, right = {...}},  -- Speaker config (optional)
  params = {frequency = 0.02, ...},   -- Physics parameters (optional)
}
```

**Returns:**
Modified simulation engine with:
- `state.acoustic_field` - Current acoustic field
- `sim:get_acoustic_field()` - Method to retrieve field
- Automatic field updates on `sim:step()`

### create_default_field()

Convenience function to create a field with sensible defaults.

```lua
local field = Acoustics.create_default_field(
  bath_length,   -- Bath length (mm), default: 2000
  frequency,     -- Frequency (Hz), default: 0.02
  amplitude      -- Amplitude (Pa), default: 100
)
```

**Returns:** Pre-configured standing wave field at t=0.

## Field Structure and Methods

A field object (returned by `StandingWaveField`) has the following structure:

### Properties

```lua
field._type           -- "acoustic_field"
field.time            -- Current simulation time (seconds)
field.frequency       -- Driving frequency (Hz)
field.amplitude       -- Pressure amplitude (Pa)
field.wavelength      -- Wavelength in medium (mm)
field.wavenumber      -- Wave number k (1/mm)
field.omega           -- Angular frequency (rad/s)
field.phase_sweep     -- Phase sweep rate (Hz)
field.sweep_phase     -- Accumulated sweep phase (radians)

-- Grid parameters
field.grid_x_points   -- Number of X grid points (81)
field.grid_z_points   -- Number of Z grid points (41)
field.x_min           -- Minimum X coordinate (mm)
field.x_max           -- Maximum X coordinate (mm)
field.z_min           -- Minimum Z coordinate (mm)
field.z_max           -- Maximum Z coordinate (mm)
field.dx              -- Grid spacing in X (mm)
field.dz              -- Grid spacing in Z (mm)

-- Pressure data
field.pressure        -- [x_idx][z_idx] = pressure magnitude (Pa)
field.phase           -- [x_idx][z_idx] = phase angle (radians)

-- Statistics
field.max_pressure    -- Maximum pressure in field (Pa)
field.min_pressure    -- Minimum pressure (always >= 0)
field.nodes           -- List of detected pressure nodes
field.antinodes       -- List of detected pressure antinodes
field.plane_offset    -- Y position of computed XZ plane (mm)
```

### Methods

#### pressure_at(x, z)

Get pressure at arbitrary point via bilinear interpolation.

```lua
local p = field:pressure_at(x, z)
```

**Parameters:**
- `x`, `z`: Coordinates in mm

**Returns:** Interpolated pressure magnitude (Pa)

**Notes:**
- Uses bilinear interpolation on grid
- Clamps to grid bounds
- Always returns non-negative value

#### normalized_pressure(x, z)

Get pressure normalized to [0, 1] range.

```lua
local p_norm = field:normalized_pressure(x, z)
```

**Returns:** Normalized pressure in [0, 1]

**Uses:** `pressure_at()` divided by `max_pressure`

#### gradient(x, z)

Compute pressure gradient at point (for force field).

```lua
local grad = field:gradient(x, z)
```

**Returns:**
```lua
{
  x = dp/dx,   -- Pressure gradient in X direction
  z = dp/dz,   -- Pressure gradient in Z direction
}
```

**Application:** Acoustic radiation forces on particles:
```lua
-- Force = -∇p (for small particles)
local force_x = -grad.x
local force_z = -grad.z
```

#### statistics()

Get field summary statistics.

```lua
local stats = field:statistics()
```

**Returns:**
```lua
{
  max_pressure = ...,        -- Maximum pressure (Pa)
  min_pressure = ...,        -- Minimum pressure (Pa)
  node_count = ...,          -- Number of detected nodes
  antinode_count = ...,      -- Number of detected antinodes
  frequency = ...,           -- Driving frequency (Hz)
  wavelength = ...,          -- Wavelength (mm)
  time = ...,                -- Current time (seconds)
}
```

#### serialize()

Export field to JSON-compatible format.

```lua
local data = field:serialize()
```

**Returns:**
```lua
{
  type = "acoustic_field",
  time = ...,
  frequency = ...,
  amplitude = ...,
  wavelength = ...,
  wavenumber = ...,
  omega = ...,
  phase_sweep = ...,
  sweep_phase = ...,
  max_pressure = ...,
  node_count = ...,
  antinode_count = ...,
}
```

**Note:** Full pressure grid is not serialized (too large). Summary data only.

## Physics Background

### Standing Wave Equation

The pressure field is computed as superposition of two plane waves:

```
p(x,z,t) = p_left(x,z,t) + p_right(x,z,t)
```

Each source contributes:

```
p_i = (A/r) * cos(k*r - ωt + φ_i)
```

Where:
- **A** = amplitude (Pa)
- **r** = distance from source (mm)
- **k** = wave number = 2π/λ (1/mm)
- **ω** = angular frequency = 2πf (rad/s)
- **t** = time (seconds)
- **φ** = phase offset (radians)

### Spherical Spreading Loss

Pressure amplitude decreases with distance as 1/r (spherical spreading). This is included in the computation for accuracy near sources.

### Standing Wave Pattern

With two sources at opposite ends, 180° out of phase:
- **Antinodes** (high pressure): Constructive interference
- **Nodes** (zero pressure): Destructive interference
- Pattern repeats every half-wavelength

### Phase Sweep

For "moving" standing waves (acoustic manipulation):
```
φ_total = φ_base + phase_sweep * (2π*t)
```

This allows the pattern to rotate/sweep at rate `phase_sweep` Hz, used in acoustic trapping/manipulation.

## Usage Examples

### Basic Field Creation

```lua
local Acoustics = require("stdlib.acoustics")

-- Default 0.02 Hz standing wave
local field = Acoustics.create_default_field()

-- Custom frequency
local field = Acoustics.create_default_field(2000, 1.0, 500)  -- 1 Hz, 500 Pa
```

### Query Pressure at Point

```lua
local field = Acoustics.create_default_field()

-- Get pressure at center of bath
local p = field:pressure_at(0, 200)

-- Get normalized for color
local p_norm = field:normalized_pressure(0, 200)
local color = Acoustics.PressureToColor(p_norm)
```

### Find Nodes and Antinodes

```lua
local field = Acoustics.create_default_field()

-- Analyze standing wave pattern
local stats = field:statistics()
print(string.format(
  "Found %d nodes and %d antinodes",
  stats.node_count, stats.antinode_count
))

-- Iterate detected positions
for _, node in ipairs(field.nodes) do
  print(string.format(
    "Node at (%.1f, %.1f) with p=%.2f Pa",
    node.x, node.z, node.pressure
  ))
end
```

### Compute Acoustic Forces

```lua
local field = Acoustics.create_default_field()

-- Get acoustic radiation force at a point
local x, z = 100, 200
local grad = field:gradient(x, z)

-- Acoustic force (for small particles)
local F_x = -grad.x
local F_z = -grad.z

-- Force magnitude and direction
local F_mag = math.sqrt(F_x^2 + F_z^2)
local theta = math.atan2(F_z, F_x)
```

### Time-Dependent Field Animation

```lua
local Acoustics = require("stdlib.acoustics")
local bath_config = Acoustics.DEFAULT_BATH
local params = Acoustics.DEFAULT_PARAMS

for t = 0, 10, 0.1 do
  local field = Acoustics.StandingWaveField(
    bath_config, {}, params, t
  )
  
  -- Render or analyze field at time t
  print(string.format(
    "t=%.2f s: max pressure = %.2f Pa",
    t, field.max_pressure
  ))
end
```

### Integration with Simulation Engine

```lua
local Mittens = require("stdlib")

-- Create flow simulation
local sim = create_simulation("coupled", "water")

-- Add acoustic field
local acoustic_config = {
  frequency = 0.02,
  amplitude = 100,
  phase_sweep = 0.1,
}
sim = Mittens.acoustics.AcousticSimulation(sim, acoustic_config)

-- Now sim includes acoustic field that updates with time
for _ = 1, 100 do
  sim:step()
  local field = sim:get_acoustic_field()
  -- Use field for coupled flow simulation
end
```

## Performance Notes

### Memory
- Field grid: 81×41 = 3,321 points per time step
- Per point: pressure (number) + phase (number) ≈ 16 bytes
- Total grid: ~53 KB (negligible)
- Nodes/antinodes: typically ~100-200 points

### Computation
- Grid computation: O(81×41) = 3,321 operations (linear in grid size)
- Node/antinode detection: O(81×41 × 5) neighbors = ~1.7K operations
- Interpolation: O(1) per query (bilinear)
- Total time step: ~10 ms on modern CPU (measurement needed)

### Optimization Opportunities
1. Cache wavelength/wavenumber per frequency
2. Only update grid when frequency/params change
3. Use lookup table for trigonometric functions
4. GPU acceleration for large grids (future)

## Design Notes

### Modularity

The Acoustics module is **standalone**:
- Does not depend on Simulation module
- Can be used independently for pure acoustic analysis
- Clean integration point via AcousticSimulation()

### Coordinate System

- **X**: Along bath length (direction of main flow)
- **Y**: Bath width (perpendicular to speakers)
- **Z**: Bath depth (vertical, often gravity direction)

Speakers are at X = ±length/2, separated along X-axis.

### Extensibility

**Future enhancements:**
1. 3D field computation (not just XZ plane)
2. Multiple frequency components (harmonics)
3. Nonlinear effects (shock formation at high amplitude)
4. Temperature-dependent speed of sound
5. Arbitrary source geometries (not just point sources)
