WHAT WAS IMPLEMENTED
================================================================================

1. POISEUILLE FLOW SOLVER (solve_flow method)
   - Formula: Q = (π·r⁴·ΔP) / (8·μ·L)
   - Computes volumetric flow rate for each channel edge
   - Takes pressure differences as input
   - Accounts for geometry (diameter, length) and fluid viscosity
   - Output: flow rates stored in SimulationState velocity field

2. PRESSURE FIELD SOLVER (solve_pressure method)
   - Builds linear system from channel network conductance
   - Gaussian elimination with partial pivoting
   - Enforces mass conservation at junctions
   - Respects boundary conditions (inlet/outlet pressures)
   - Solves for interior node pressures

3. ACOUSTIC COUPLING (couple_acoustic_force method)
   - Samples acoustic pressure field at each node location
   - Computes pressure gradients for body force calculation
   - Stores force magnitude for future use in coupled simulations
   - Enables acoustic manipulation of fluid flow

4. TIME STEPPING (updated step method)
   - Updates acoustic field evolution
   - Solves pressure field from boundary conditions
   - Applies acoustic body forces
   - Computes flow rates via Poiseuille
   - Advances time and triggers output

5. LINEAR SOLVER (_solve_linear_system helper)
   - Gaussian elimination with partial pivoting
   - Singular matrix detection
   - Suitable for small-to-medium networks (<100 nodes)

KEY TECHNICAL DETAILS
================================================================================

Physics Model:
- 1D circular channel flow in laminar regime (Re << 1)
- Pressure-driven Poiseuille flow: Q ∝ r⁴, 1/μ, 1/L
- Mass conservation enforced at network junctions
- Acoustic body forces F = -∇p integrated as pressure modifications

Numerical Method:
- Direct linear solver suitable for <100 nodes
- Gaussian elimination with partial pivoting for stability
- Division by zero prevention (minimum length constraint)
- Matrix singularity detection

Integration:
- Uses ChannelNetwork with nodes and edges
- Leverages FluidProperties for material data
- Hooks into SimulationState for velocity/pressure storage
- Compatible with Acoustics module for field sampling
